# Log 文件输出实现

## 已确认规则


| 项目  | 规则                                                  |
| --- | --------------------------------------------------- |
| 范围  | Info / Warning / Error / Exception 全部写入             |
| 路径  | 项目根目录 `Logs` 文件夹                                    |
| 文件名 | 时间戳格式 `yyyyMMdd_HHmmss.log`，如 `20260225_143052.log` |
| 行格式 | `[HH:mm:ss.fff] [Info] 消息内容`                        |


## 实现方案

### 1. 修改 [Assets/GameFramework/Utility/Log.cs](Assets/GameFramework/Utility/Log.cs)

**新增内容：**

- 获取日志目录：`Path.GetDirectoryName(Application.dataPath)` 得到项目根目录，拼接 `Logs`
- 首次写入时创建目录：`Directory.CreateDirectory(logDir)`
- 单次 Play 共享一个文件：静态字段 `_logFilePath`、`_logWriter`，首次 Log 时按当前时间生成文件名并创建 `StreamWriter`
- 私有方法 `WriteToFile(string level, object message)`：写入 `[HH:mm:ss.fff] [level] message`，并 `Flush`
- 在每个 `Info`/`Warning`/`Error`/`Exception` 方法末尾调用 `WriteToFile`（先 Debug 输出，再写文件）

**代码结构示意：**

```csharp
private static string _logFilePath;
private static StreamWriter _logWriter;

private static void WriteToFile(string level, object message)
{
    // 首次调用时初始化 _logFilePath 和 _logWriter
    // 格式：[HH:mm:ss.fff] [level] message
    // _logWriter.WriteLine(...); _logWriter.Flush();
}
```

**要点：**

1. 路径使用 `Application.dataPath` 父目录，保证编辑器与构建后都能正确得到项目根路径
2. 每次写入后 `Flush()`，避免进程异常退出时丢日志
3. 仅在 `UNITY_EDITOR` 下执行文件写入（与现有 `[Conditional]` 保持一致）
4. 使用 `lock` 保证多线程安全（若有后台线程打 Log）

### 2. 依赖

- `System.IO`：`Path`、`Directory`、`StreamWriter`
- `System`：`DateTime`

### 3. 生命周期

- 首次 Log 时创建目录和文件，打开 `StreamWriter`
- 单次 Play 内复用同一个 `StreamWriter`
- 进程结束或 Domain Reload 时由系统回收，不做显式 `Close`；若需更严谨，可在 `[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)]` 中检测 Domain Reload 并关闭 `_logWriter`

## 输出示例

**Console：** 与现在一致

```
[14:30:55.456] [Warning] [AreaTriggerTest] 未配置形状
[14:31:00.789] [Error] 某错误信息
```

## 注意事项

1. 项目根目录需确认：若通过 `Path.GetDirectoryName(Application.dataPath)` 得到的路径不符合预期，可改为可配置路径
2. `Assets` 下的 Log 目录已废弃，改用项目根目录 `Logs`
