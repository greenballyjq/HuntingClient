## 1. 功能概述

本模块提供一个“更上层”的粒子特效管理能力，面向使用侧屏蔽粒子细节（Play/Stop/尾巴/回收），并与现有对象池体系整合：

- **仅处理 ParticleSystem 特效**
- **统一要求：所有特效 Prefab 必须挂 `ParticleEffectItem` 脚本**
- **复用 `GameObjectPoolManager` 对象池**
- 支持：
  - 一次性特效播放完自动回收（OneShot）
  - 循环特效播放（Loop，必须手动 Stop）
  - 持续时间播放（Duration，到时间后软停止并等待尾巴结束再回收）
  - 停止语义（Stop）：
    - Soft：停止发射，等待尾巴结束再回收
    - Immediate：立刻清屏并回收

## 3. 组件说明

### 3.1 `ParticleEffectItem`
挂在粒子特效 Prefab 上，负责：
- 实现 `IPoolItem`
  - `OnSpawned()`：取出时清理残留并播放
  - `OnDespawned()`：回收前立即停止并清屏（保证下次复用干净）
- 实现 `IEffectItem`
  - `Play()` / `StopSoft()` / `StopImmediate()`
  - `IsAlive()`：用于管理器等待尾巴结束
  - `GetEstimatedDuration()`：用于一次性特效估算等待

> 注意：此脚本是“粒子特效复用正确性”的核心。管理器不负责清理细节。

### 3.2 `EffectManager`
作为管理器提供上层 API：
- `PlayOneShot(...)` / `PlayOneShotAsync(...)`
- `PlayLoop(...)`
- `PlayForDuration(...)`
- `Stop(obj, mode)`
- `Recycle(obj)`

管理器内部维护一个 “GameObject -> CancellationTokenSource” 映射，用于取消尚未完成的自动回收任务，避免重复回收。

## 2. 依赖

- `GameObjectPoolManager`：负责实例复用与回收
- `UniTask`：用于异步播放与等待回收
- `ParticleEffectPoolItem`：挂在特效 prefab 上，实现 `IPoolItem`

## 3. 资源要求（必须）

每一个粒子特效 prefab **必须挂载组件**：

- `ParticleEffectPoolItem`

该组件负责：

- `OnSpawned()`：清理残留并播放
- `OnDespawned()`：立即停止并清理

如果 prefab 缺少该组件，管理器会输出 `Debug.LogError` 并立即回收该对象。

## 4. 初始化与生命周期

`ParticleEffectManager` 按你项目 Manager 体系初始化/释放即可。

- 初始化：`Init(...)`
- 清理：`Cleanup()`
- 释放：`Dispose()`

释放/清理会：

- 取消所有自动回收任务
- 回收所有仍处于活跃状态的特效对象

## 5. 播放 API

### 5.1 预制体方式

#### 一次性播放（自动回收）

```
GameObject fx = particleEffectManager.PlayOneShot(prefab, position, direction);
```

#### 循环播放（不自动回收，需手动 Stop）

```
GameObject fx = particleEffectManager.PlayLoop(prefab, position, direction);
```

#### 播放指定时长（到点软停止并回收）

```
GameObject fx = particleEffectManager.PlayForDuration(prefab, position, direction, duration);
```

### 5.2 路径方式（异步加载 + 池化）

> 路径由 `GameObjectPoolManager.SpawnAsync` 负责加载与缓存。

#### 一次性播放（自动回收）

```
GameObject fx = await particleEffectManager.PlayOneShotAsync(path, position, direction);
```

#### 循环播放（不自动回收）

```
GameObject fx = await particleEffectManager.PlayLoopAsync(path, position, direction);
```

#### 播放指定时长（到点软停止并回收）

```
GameObject fx = await particleEffectManager.PlayForDurationAsync(path, position, direction, duration);
```

## 6. 停止与回收 API

### 6.1 软停止（推荐用于循环特效）

停止发射，等待尾巴（存活粒子）播放完毕后回收。

```
particleEffectManager.StopEffect(fx, EffectStopMode.Soft);
```

### 6.2 立即停止

立刻停止并清理后回收（用于打断、强制清屏）。

```
particleEffectManager.StopEffect(fx, EffectStopMode.Immediate);
```

### 6.3 立即回收

不关心尾巴，直接回收（内部会取消自动回收任务）。

```
particleEffectManager.RecycleEffect(fx);
```

## 7. 使用约束（必须遵守）

1. **不要绕过特效管理器回收特效对象**
   - 不要直接调用：`GameObjectPoolManager.Despawn(fx)`
   - 请使用：`StopEffect(...)` 或 `RecycleEffect(...)`
2. 循环特效必须由业务在合适时机调用 `StopEffect` 或 `RecycleEffect`，否则会一直存在。
3. `direction == Vector3.zero` 时不改变旋转；否则使用 `Quaternion.LookRotation(direction)` 设置朝向。

## 8. 自动回收行为说明

### 8.1 OneShot 自动回收

- 对象进入 OneShot 模式后会启动自动回收任务。
- 若资源配置为 loop，OneShot 模式会先执行软停止避免永不结束。
- 通过轮询 `ParticleEffectPoolItem.IsAlive()` 等待所有粒子完全结束，再回收。

### 8.2 Duration 自动回收

- 先等待 `duration` 秒。
- 到点后软停止并等待粒子全部结束，再回收。

### 8.3 为什么要取消令牌（CancellationToken）

当你手动停止/回收时，会取消自动回收任务，避免：

- 已回收对象被二次回收
- 对象已经复用给新特效后，被旧任务误回收

## 9. 常见用法示例

### 9.1 命中特效（一次性）

```
particleEffectManager.PlayOneShot(hitFxPrefab, hitPos, hitNormal);
```

### 9.2 持续燃烧特效（循环 + 软停止）

```
GameObject fx = particleEffectManager.PlayLoop(burnFxPrefab, pos, dir);

// ...状态结束时
particleEffectManager.StopEffect(fx, EffectStopMode.Soft);
```

### 9.3 Buff 光环（指定时长）

```
particleEffectManager.PlayForDuration(buffAuraPrefab, pos, Vector3.forward, 5f);
```
